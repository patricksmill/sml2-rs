**Slice status: COMPLETE** — this describes control-flow coverage, not implementation verification.
**Address:** ROM `0x0AD93`, bank `$02` (2 decimal), CPU `$6D93`.
**Selected bank at entry:** `$02`.
**Anims:** boss:26 (Wario Form 3 boss body).
**Policy:** [PORTING.md](../../PORTING.md).

Implemented in `crates/sml2-core/src/objects/wario/form3.rs` with typed `Actor` state and `form3_adapter.rs`.
Wired in `crates/sml2-core/src/objects/dispatch.rs` under dispatch arm `0xAD93`.

## States and Subroutines
- **State 0**: Initial spawn setup. Spawns child anim 25 (form 2 helmet/intro falling child) into an empty slot, sets timer = 32, transitions to state 12.
- **State 1**: Hit stun animation handling (`update_hit_stun`).
- **State 2**: Defeat fall. Uses `boss_picker_profile` table (cap 21). Sets `boss_clear_flag = 1`. When `y >= 138`, plays defeat music (`music = 24`), sets timer = 0, transitions to state 13.
- **State 3**: Prepares trajectory child throw (anim 27). Plays `sfx2 = 8`. Sets timer = 80, transitions to state 4 (facing left) or state 5 (facing right).
- **States 4 & 5**: Walking left/right. 4-frame animation cycle (`0xB339` / `0xB356`). Horizontal wall turnarounds at `x < 24` and `x >= 152`. Player proximity detection: when `dist_x < 48`, triggers jump (transitions to state 6 or 7). Checks if child anim 27 despawned; if so, re-arms throw.
- **States 6 & 7**: Jumping (rising and falling). Uses high rise (`RiseProfile::High`, cap 27) if player is Fire Mario (`powerup == 2`), otherwise low rise (`RiseProfile::Low`, cap 15). Returns to walking states 4/5 upon landing.
- **States 8 & 9**: Defeat crying / spawn drop child 28. Sets timer = 255. Spawns drop child (anim 28, sprite 108).
- **State 10**: Defeat running offscreen right. Increments x by 3 on even frames. Once `screen.x >= 192`, sets `effects.done = true`, `effects.fight_phase = Some(3)`, `effects.scene_state = Some(0)` to trigger the ending sequence walk.
- **State 11**: Intro pause: waits for `fade_timer == 0`.
- **State 12**: Waits for intro child 25 to land (`child_landed == true`), then counts down timer to state 11.
- **State 13**: Defeat ground delay (256 frames), transitions to crying state 8.
