# Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A normal launch opens a library that imports one allow-listed Super Mario Land 2 ROM into the user cache and plays that install, with SML2DX as an optional layer on the same screen.

**Architecture:** `sml2-extract` owns the allow-list, the ROM-only extract, and atomic directory publish. `sml2-desktop` owns the library state, the cold-start gate, and the existing DX importer pointed at the published directory. `--play`, `--file-select`, `--room`, `--reveal`, `--assets`, and `--smoke-frames` skip the library. `--title` does not.

**Tech Stack:** Rust 2021, existing `sml2-extract` / `sml2-desktop` / `sml2-dx` crates, `sha2` 0.10, `serde_json`, `eframe` 0.33, `directories` 6.

## Global Constraints

- First allow-list entry: revision `ue-v1.0`, display name `Super Mario Land 2`, length 524288, SHA-256 `5450dce1bd0c073964c374b5b5b5729dce8d00f2e807892c34af32b8bce1392e`, offset table `ue-v1.0`. Acceptance is that length and digest.
- Read at most 524289 bytes. Do not copy the ROM into the cache or the repo.
- Vanilla cache is `ProjectDirs::from("", "", "sml2-rs").cache_dir().join("vanilla")`. DX cache stays `cache_dir().join("dx")`.
- Manifest importer version is `1` and schema is `1`. Settings version stays `3`. `vanilla` defaults to absent.
- Publish commits by directory rename. A failed settings write restores the previous install. DX is deleted only after that commit, and only when `base_fingerprint` changes. A failed DX delete does not roll back vanilla.
- No committed ROM, patch, extracted tree, imported graphic, or reference render. The ignored parity test reads a local `baserom.gb`.
- Level packs and the level editor rows are inactive and read `Not in this version`. The scenery editor stays on the pause menu. Quit to title stays as it is.
- Settings → Mods keeps widescreen, camera zoom, and character. It loses the DX toggle and the DX import.

```rust
use sha2::{Digest, Sha256};

pub const MAX_READ: usize = 524_288 + 1;
pub const IMPORTER_VERSION: u32 = 1;
pub const SCHEMA: u32 = 1;

pub struct Revision {
    pub id: &'static str,
    pub name: &'static str,
    pub len: usize,
    pub sha256: &'static str,
    pub offsets: &'static str,
}

pub const REVISIONS: &[Revision] = &[Revision {
    id: "ue-v1.0",
    name: "Super Mario Land 2",
    len: 524_288,
    sha256: "5450dce1bd0c073964c374b5b5b5729dce8d00f2e807892c34af32b8bce1392e",
    offsets: "ue-v1.0",
}];

pub enum IdentifyError {
    TooLong,
    Unsupported { len: usize, sha256: String },
}

pub fn sha256(bytes: &[u8]) -> String {
    format!("{:x}", Sha256::digest(bytes))
}

pub fn identify(bytes: &[u8]) -> Result<&'static Revision, IdentifyError> {
    if bytes.len() > 524_288 {
        return Err(IdentifyError::TooLong);
    }
    let digest = sha256(bytes);
    REVISIONS
        .iter()
        .find(|revision| revision.len == bytes.len() && revision.sha256 == digest)
        .ok_or(IdentifyError::Unsupported {
            len: bytes.len(),
            sha256: digest,
        })
}
```

```rust
use std::fs;
use std::path::{Path, PathBuf};

#[derive(serde::Serialize, serde::Deserialize, Clone, PartialEq, Eq)]
pub struct Manifest {
    pub revision: String,
    pub sha256: String,
    pub importer_version: u32,
    pub schema: u32,
}

pub enum PublishError {
    Prepare(String),
    Validate(String),
    Io(String),
}

pub struct Commit {
    pub backup: Option<PathBuf>,
}

pub fn publish_directory(
    dest: &Path,
    manifest: &Manifest,
    prepare: impl FnOnce(&Path) -> Result<(), PublishError>,
    validate: impl FnOnce(&Path) -> Result<(), PublishError>,
) -> Result<Commit, PublishError> {
    let parent = dest.parent().ok_or_else(|| PublishError::Io("vanilla cache has no parent".into()))?;
    fs::create_dir_all(parent).map_err(|e| PublishError::Io(e.to_string()))?;
    let stage = parent.join(format!("vanilla.stage.{}", std::process::id()));
    let _ = fs::remove_dir_all(&stage);
    fs::create_dir_all(&stage).map_err(|e| PublishError::Io(e.to_string()))?;
    if let Err(error) = prepare(&stage) {
        let _ = fs::remove_dir_all(&stage);
        return Err(error);
    }
    let bytes = serde_json::to_vec_pretty(manifest).map_err(|e| PublishError::Io(e.to_string()))?;
    if let Err(error) = fs::write(stage.join("manifest.json"), bytes) {
        let _ = fs::remove_dir_all(&stage);
        return Err(PublishError::Io(error.to_string()));
    }
    if let Err(error) = validate(&stage) {
        let _ = fs::remove_dir_all(&stage);
        return Err(error);
    }
    let backup = parent.join(format!("vanilla.bak.{}", std::process::id()));
    let _ = fs::remove_dir_all(&backup);
    let had_dest = dest.exists();
    if had_dest {
        fs::rename(dest, &backup).map_err(|e| PublishError::Io(e.to_string()))?;
    }
    if let Err(error) = fs::rename(&stage, dest) {
        if had_dest {
            let _ = fs::rename(&backup, dest);
        }
        let _ = fs::remove_dir_all(&stage);
        return Err(PublishError::Io(error.to_string()));
    }
    Ok(Commit {
        backup: had_dest.then_some(backup),
    })
}

pub fn rollback(dest: &Path, commit: &Commit) -> Result<(), PublishError> {
    let discarded = dest.with_extension("discarded");
    let _ = fs::remove_dir_all(&discarded);
    if dest.exists() {
        fs::rename(dest, &discarded).map_err(|e| PublishError::Io(e.to_string()))?;
    }
    if let Some(backup) = &commit.backup {
        fs::rename(backup, dest).map_err(|e| PublishError::Io(e.to_string()))?;
    }
    let _ = fs::remove_dir_all(&discarded);
    Ok(())
}

pub fn discard_backup(commit: &Commit) {
    if let Some(backup) = &commit.backup {
        let _ = fs::remove_dir_all(backup);
    }
}
```

```rust
pub fn extract(rom: &[u8], dest: &Path) -> Result<&'static Revision, String> {
    let revision = identify(rom).map_err(|error| match error {
        IdentifyError::TooLong => "ROM is longer than the allow-list".into(),
        IdentifyError::Unsupported { len, sha256 } => {
            format!("Unsupported vanilla ROM ({len} bytes, SHA-256 {sha256})")
        }
    })?;
    if revision.offsets != "ue-v1.0" {
        return Err(format!("no offset table for {}", revision.offsets));
    }
    crate::cartridge::emit(rom, dest).map_err(|e| e.to_string())?;
    crate::ending::emit(rom, dest).map_err(|e| e.to_string())?;
    crate::map::emit(rom, dest).map_err(|e| e.to_string())?;
    crate::castle::emit(rom, dest).map_err(|e| e.to_string())?;
    crate::front_end::emit_rom(rom, dest).map_err(|e| e.to_string())?;
    emit_game(rom, dest)?;
    Ok(revision)
}
```

```rust
pub enum Row {
    Rom,
    Dx,
    Packs,
    Editor,
    Play,
    Exit,
}

#[derive(Default)]
pub struct Library {
    pub vanilla_ready: bool,
    pub checking: bool,
    pub revision_name: String,
    pub dx_installed: bool,
    pub dx_mode: bool,
    pub importing: bool,
}

impl Library {
    pub fn play_enabled(&self) -> bool {
        self.vanilla_ready && !self.checking && !self.importing
    }

    pub fn play_label(&self) -> &'static str {
        if self.dx_installed && self.dx_mode {
            "Play with DX"
        } else {
            "Play"
        }
    }

    pub fn row_enabled(&self, row: Row) -> bool {
        match row {
            Row::Rom => !self.importing,
            Row::Dx => self.vanilla_ready && !self.checking && !self.importing,
            Row::Packs | Row::Editor => false,
            Row::Play => self.play_enabled(),
            Row::Exit => !self.importing,
        }
    }

    pub fn row_status(&self, row: Row) -> String {
        match row {
            Row::Rom if self.checking => "Checking install…".into(),
            Row::Rom if self.vanilla_ready => self.revision_name.clone(),
            Row::Rom => "Required".into(),
            Row::Dx if !self.vanilla_ready || self.checking => "Add a ROM first".into(),
            Row::Dx if !self.dx_installed => "not installed".into(),
            Row::Dx if self.dx_mode => "On".into(),
            Row::Dx => "Off".into(),
            Row::Packs | Row::Editor => "Not in this version".into(),
            Row::Play => self.play_label().into(),
            Row::Exit => "Quit".into(),
        }
    }
}
```

```rust
fn validate_assets(stage: &Path) -> Result<(), sml2_extract::vanilla::PublishError> {
    let assets = sml2_runtime::content::SessionAssets::load_from(
        &sml2_runtime::content::ExtractedContent::new(stage),
    )
    .map_err(|e| sml2_extract::vanilla::PublishError::Validate(e.to_string()))?;
    for id in 0..32 {
        assets.level(id).map_err(sml2_extract::vanilla::PublishError::Validate)?;
    }
    Ok(())
}
```

`check_install` reads `manifest.json`, rejects an importer version or schema other than `1` with `This install was made by an older importer.
